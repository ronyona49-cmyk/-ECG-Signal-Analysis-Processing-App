# 🫀 ECG Signal Analysis & Processing App

A MATLAB-based GUI application developed using App Designer for analyzing and processing Electrocardiogram (ECG) signals.

## 🚀 Key Features
* **Interactive GUI:** A user-friendly interface to easily load, visualize, and analyze raw ECG data files.
* **Signal Processing & Filtering:** Includes a built-in noise filtering toggle and an adjustable threshold to clean the raw signal for accurate algorithmic analysis.
* **R-Peak Detection:** Automatically identifies and plots R-peaks directly over the ECG signal in real-time.
* **Tachogram & Heart Rate Metrics:** Calculates the interval between consecutive beats, plotting a detailed Tachogram alongside key metrics (Average BPM, Min/Max BPM, and total beat count).
* **Data Export:** Instantly exports the test summary and calculated data to an Excel spreadsheet (`.xlsx`) and saves the graphical plots as images for external reporting.

## 🛠️ Built With
* **MATLAB & App Designer**
* **MATLAB Signal Processing Toolbox**

## 💻 How to Use
1. Clone this repository.
2. Open the `.mlapp` project file in MATLAB.
3. Click **Run**.
4. Use **Load ECG file** to import your data, adjust the noise/threshold settings, and click **Find peaks** to generate your reports!
